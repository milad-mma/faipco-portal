# اطلاعات بانکی پرسنل

ماژول «اطلاعات بانکی» در پنل کاربری (پروفایل → «اطلاعات بانکی»، مسیر `/bank-info`) و پنل ادمین
(«اطلاعات بانکی پرسنل»، مسیر `/bank-accounts/admin`). Migration 118.

## تصمیم‌های کاربر
- بانک‌ها از پنل ادمین و **به تفکیک سایت** تعریف می‌شوند و تعدادشان محدود نیست (فعلاً دو بانک اجباری).
- برای هر بانک، حالت هر فیلد (شماره حساب، شبا، شماره کارت) در پنل ادمین تعیین می‌شود: اجباری / اختیاری / نمایش داده نشود.
- «اجباری» فقط **یادآوری** است (هشدار در داشبورد و پروفایل)، پرتال بسته نمی‌شود.
- پرسنل اطلاعاتش را **آزادانه** تغییر می‌دهد؛ هر تغییر با مقدار قدیم و جدید در سابقه ثبت می‌شود.

## داده
- `bank_definitions`: site_id، name، is_required، account_number_mode / sheba_mode / card_number_mode
  (required/optional/hidden)، is_active، sort_order. نام در هر سایت یکتاست؛ حداقل یک فیلد باید نمایش داده شود.
- `employee_bank_accounts`: یک ردیف به ازای پرسنل × بانک (account_number، sheba = IR + ۲۴ رقم، card_number).
- `employee_bank_account_history`: bank_name (در لحظه)، changes = {field: [قدیم، جدید]}، changed_by، by_admin.
- حذف بانکی که پرسنل برایش اطلاعات ثبت کرده ممکن نیست (باید غیرفعال شود تا اطلاعات حفظ شود). فیلدی که بعداً «مخفی» شود،
  مقدار قبلی‌اش دست نمی‌خورد.

## اعتبارسنجی (`core/bank_rules.py`، هم‌سو با `frontend/src/utils/bank.js`)
- ارقام فارسی/عربی به لاتین؛ فاصله، خط تیره، نقطه و نیم‌فاصله حذف.
- شبا: کاربر فقط **۲۴ رقم** وارد می‌کند (IR ثابت کنار فیلد است؛ اگر با IR بچسباند حذف می‌شود) و در دیتابیس «IR» + ۲۴ رقم
  ذخیره می‌شود (دستور کاربر). رقم کنترل IBAN (mod 97) بررسی می‌شود؛ سرور هر دو شکل ورودی را می‌پذیرد.
- شماره کارت: ۱۶ رقم با Luhn. شماره حساب: ۵ تا ۲۰ رقم.

## مجوزها و دسترسی
- `bank_accounts.view`: گزارش پرسنل فعال × بانک‌ها، خروجی Excel، سابقه‌ی تغییرات (محدود به سایت‌های مجاز).
- `bank_accounts.manage`: تعریف/ویرایش/حذف بانک‌های سایت و اصلاح اطلاعات پرسنل (در سابقه با «منابع انسانی»).
- اطلاعات هر پرسنل فقط برای خودش و دارندگان مجوز همان سایت قابل مشاهده است.
- `/auth/me`: `can_view_bank_accounts`، `can_manage_bank_accounts`، `bank_info_missing`.

## API (`/bank-accounts`)
- پرسنل: `GET /me`، `PUT /me/{bank_id}`، `GET /me/history`.
- مدیریت: `GET|POST /admin/sites/{site_id}/banks`، `PUT|DELETE /admin/banks/{id}`، `GET /admin/report`
  (site_id، search، status=complete|missing)، `GET /admin/export`، `GET /admin/employees/{id}/history`،
  `PUT /admin/employees/{id}/banks/{bank_id}`.

## خروجی Excel
یک سطر برای هر پرسنل؛ برای هر بانک ستون‌های فیلدهای غیرمخفی («بانک ملت - شماره شبا»)؛ شماره‌ها با قالب متن (صفرهای
ابتدای شماره حساب حفظ می‌شود).
