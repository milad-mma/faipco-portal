# مدیریت مستقیم دیتابیس با pgAdmin 4

معادل PostgreSQL برای phpMyAdmin — مدیریت مستقیم جداول، اجرای Query، مشاهده
داده. **فقط برای Admin/توسعه‌دهنده، نه بخشی از خودِ پرتال** — پرسنل عادی
هیچ ارتباطی با این ابزار ندارند.

## چرا pgAdmin4، نه Apache

pgAdmin رسماً معمولاً با Apache HTTPD نصب می‌شود. برای این‌که سرور شما یک
Web Server کاملاً جدا (علاوه بر Nginx خودِ پرتال) نداشته باشد، نصب اینجا
دقیقاً با همان معماری خودِ FAIPCO Portal انجام شده: یک Virtual Environment
پایتون جدا + Gunicorn (به‌جای Uvicorn) + یک Location جدید در Nginx —
همانی که برای خودِ Backend استفاده می‌شود.

## ⚠️ فقط از شبکه محلی — نه اینترنت

این مهم‌ترین بخش نصب است. pgAdmin **هرگز از طریق Reverse Proxy خارجی پرتال
routing نمی‌شود** — یک `server` جدا در Nginx، روی پورت ۸۰۸۰، بدون هیچ
`server_name` عمومی، با `allow`/`deny` محدود به رنج IP شبکه محلی. یعنی حتی
اگر کسی از بیرون شبکه شرکت دقیقاً همان IP سرور و پورت ۸۰۸۰ را هم امتحان
کند، رد می‌شود. یک لایه دوم هم در سطح Firewall (`ufw`) همین محدودیت را
تکرار می‌کند.

خودِ Gunicorn هم فقط روی `127.0.0.1` (نه `0.0.0.0`) گوش می‌دهد — یعنی حتی
اگر یک‌جا در تنظیمات Nginx/Firewall اشتباهی رخ دهد، خودِ فرآیند pgAdmin
مستقیماً از بیرون همین سرور اصلاً در دسترس نیست.

## نصب

```bash
sudo bash install-pgadmin.sh \
  --allowed-network 192.168.99.0/24 \
  --admin-email you@company.com
```

| آرگومان | توضیح | پیش‌فرض |
|---|---|---|
| `--allowed-network` | رنج IP شبکه محلی مجاز (فرمت CIDR) — **حتماً با رنج واقعی شبکه خودتان عوض کنید** | `192.168.99.0/24` (فقط یک نمونه) |
| `--admin-email` | ایمیل ورود به pgAdmin (الزامی) | — |
| `--admin-password` | رمز عبور ورود — اگر ندهید، یک رمز تصادفی تولید و در پایان نصب یک‌بار نمایش داده می‌شود | تصادفی |
| `--port` | پورت داخلی Gunicorn (بین خودِ سرور و Nginx، نه پورت عمومی) | `5050` |

بعد از نصب، آدرس دسترسی (`http://<IP-سرور>:8080`) و رمز عبور یک‌بار روی
صفحه نمایش داده می‌شود — همان لحظه در یک Password Manager ذخیره کنید.

## بعد از ورود — اتصال به دیتابیس پرتال

pgAdmin خودش هیچ اتصالی به دیتابیس از پیش ندارد — بعد از ورود، یک Server
جدید دستی اضافه کنید:

- **Host**: `localhost` یا `127.0.0.1` (چون pgAdmin روی همین سرور نصب شده)
- **Port**: `5432`
- **Database/Username/Password**: همان مقادیر `DATABASE_URL` در
  `backend/.env` خودِ پرتال

## نکات امنیتی مهم

- ⚠️ رمز عبوری که وارد pgAdmin می‌کنید (برای اتصال به دیتابیس پرتال) کاملاً
  **جدا** از رمز ورود خودِ pgAdmin است — دومی را در همان اولین نصب تعیین
  کردید.
- این ابزار عمداً از HTTPS استفاده نمی‌کند (فقط HTTP ساده روی پورت ۸۰۸۰) —
  چون فرض بر این است که فقط از شبکه داخلی و قابل‌اعتماد در دسترس است، نه
  اینترنت عمومی. اگر بعداً تصمیم گرفتید از خارج شبکه هم (مثلاً با VPN) به آن
  دسترسی داشته باشید، حتماً TLS هم اضافه کنید.
- حساب کاربری pgAdmin که با `--admin-email` ساختید، دسترسی کامل به **هر
  جدولی** در دیتابیس (شامل کد ملی، حقوق، اطلاعات کامل پرسنلی) دارد — رمز
  عبورش را با همان دقتی نگه دارید که رمز Admin خودِ پرتال را نگه می‌دارید.

## حذف نصب

```bash
sudo systemctl disable --now pgadmin4
sudo rm /etc/systemd/system/pgadmin4.service
sudo rm /etc/nginx/sites-enabled/pgadmin4 /etc/nginx/sites-available/pgadmin4
sudo systemctl reload nginx
sudo rm -rf /opt/pgadmin4 /var/lib/pgadmin4 /var/log/pgadmin4
sudo userdel pgadmin4
```
