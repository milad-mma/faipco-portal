# محدودکردن ورود به رنج‌های IP مجاز (ضدVPN)

از پنل Admin → «رنج‌های IP مجاز» قابل مدیریت است.

## رفتار

- اگر **هیچ رنجی ثبت نشده باشد**، این محدودیت کاملاً غیرفعال است — همه از
  هر جایی می‌توانند وارد شوند (رفتار پیش‌فرض، برای جلوگیری از قفل‌شدن
  تصادفی همه).
- به‌محض ثبت **حداقل یک رنج**، ورود فقط از همان رنج‌ها مجاز می‌شود. تلاش
  ورود از هر IP دیگری (چه با VPN چه بدون VPN) رد می‌شود — پیام و یک Dialog
  مشخص در صفحه ورود نشان داده می‌شود که از کاربر می‌خواهد VPN را قطع کند.
- فرمت هر رکورد CIDR است: یک IP تکی (`203.0.113.5/32`) یا یک رنج
  (`192.168.1.0/24`).

## نکته فنی مهم: تشخیص IP واقعی کاربر پشت چند لایه Proxy

این سرور پشت Nginx است که خودش ممکن است پشت یک Reverse Proxy خارجی برای
SSL باشد (دو لایه Proxy). چون Nginx با
`proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;` این هدر را
به هر لایه اضافه (نه جایگزین) می‌کند، **اولین مقدار** در `X-Forwarded-For`
همیشه IP اصلی کاربر است — این پروژه دقیقاً همین را می‌خواند
(`app/core/ip_allowlist.py`).

⚠️ اگر آن Reverse Proxy خارجی این هدر را درست تنظیم نکند (جایگزین کند به‌جای
اضافه‌کردن)، تشخیص IP اشتباه می‌شود. قبل از فعال‌سازی جدی این قابلیت، حتماً
با یک IP تستی مطمئن شوید مقدار درستی تشخیص داده می‌شود (می‌توانید موقتاً
یک لاگ از IP تشخیص‌داده‌شده در `get_client_ip()` اضافه کنید).

## مجوز

فقط `system.ip_allowlist` — که مثل `system.backup` و `system.cache_bust`،
به هیچ نقشی داده نمی‌شود و فقط از طریق `is_superuser` قابل‌استفاده است.
