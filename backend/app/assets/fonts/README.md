# فونت فارسی برای PDF فیش حقوقی

سیستم «اطلاعیه فیش حقوقی» برای تولید PDF فیش هر پرسنل، به یک فونت TTF که
حروف فارسی/عربی را پشتیبانی کند نیاز دارد (چون فونت‌های پیش‌فرض داخل ReportLab
مثل Helvetica فقط لاتین هستند و متن فارسی را یا خالی نشان می‌دهند یا به‌شکل
نامفهوم).

## کاری که باید انجام دهید

یک فونت فارسی رایگان (پیشنهاد: [Vazirmatn](https://github.com/rastikerdar/vazirmatn))
دانلود کنید و فایل آن را دقیقاً با همین نام در همین پوشه قرار دهید:

```
backend/app/assets/fonts/Vazirmatn-Regular.ttf
```

اگر می‌خواهید از فونت یا مسیر دیگری استفاده کنید، مقدار `PERSIAN_FONT_PATH`
را در `backend/.env` تنظیم کنید.

## اگر این فایل را نگذارید چه می‌شود؟

سیستم از کار نمی‌افتد — PDF همچنان تولید می‌شود، ولی متن فارسی در آن یا خالی
یا نادرست (بدون اتصال حروف/راست‌به‌چپ) نمایش داده می‌شود. یک هشدار هم در
Log بک‌اند ثبت می‌شود (`فونت فارسی یافت نشد: ...`) تا متوجه این نقص بشوید.
