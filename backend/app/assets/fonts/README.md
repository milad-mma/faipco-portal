# فونت فارسی برای PDF فیش حقوقی

سیستم «اطلاعیه فیش حقوقی» برای تولید PDF فیش هر پرسنل، به یک فونت TTF که
حروف فارسی/عربی را پشتیبانی کند نیاز دارد.

## وضعیت فعلی

فایل `Tahoma.ttf` همراه همین پوشه قرار داده شده و به‌عنوان فونت پیش‌فرض
(`PERSIAN_FONT_PATH`) تنظیم شده — چون این دقیقاً همان فونتی است که خودِ
گزارش SSRS سازمان (فیش حقوقی اصلی) با آن ساخته می‌شود، پس نزدیک‌ترین تطابق
ظاهری (مخصوصاً برای اعداد) را می‌دهد.

⚠️ **نکته حقوقی مهم**: Tahoma یک فونت **مالکیتی مایکروسافت** است، نه
متن‌باز/رایگان — طبق شرایط لایسنس مایکروسافت، توزیع مجدد این فایل (مثلاً
Push کردن در یک مخزن Git عمومی یا اشتراک‌گذاری خارج از سازمان) ممکن است
مجاز نباشد. این فایل صرفاً چون توسط خودِ سازمان (که به آن دسترسی/لایسنس
Windows/Office دارد) صراحتاً برای این پروژه ارائه شد، اینجا قرار گرفته.
مسئولیت رعایت شرایط لایسنس مایکروسافت بر عهده سازمان است — اگر قرار است
این مخزن کد در جای دیگری (مثلاً یک مخزن عمومی GitHub) قرار بگیرد، بهتر است
این فایل را حذف و به‌جایش یک فونت متن‌باز (پایین همین صفحه) استفاده کنید.

**محدودیت شناخته‌شده**: فقط نسخه Regular ارائه شده (بدون Bold). متن‌هایی که
باید Bold نمایش داده شوند (عنوان‌ها، برچسب‌های نوار مشخصات) با همان وزن
عادی Tahoma نمایش داده می‌شوند — اگر یک فایل `Tahoma-Bold.ttf` (یا با هر
نامی که در `_bold_variant_path` در `payroll_pdf.py` جستجو می‌شود) در همین
پوشه اضافه کنید، کد خودکار آن را هم پیدا و برای Bold استفاده می‌کند.

## اگر فایل Tahoma در سرور موجود نباشد چه می‌شود؟

سیستم از کار نمی‌افتد — به‌صورت خودکار به **DejaVu Sans Condensed** (که
معمولاً از قبل روی توزیع‌های اوبونتو/دبیان نصب است و فارسی را پشتیبانی
می‌کند، هرچند نه دقیقاً هم‌شکل Tahoma) سقوط می‌کند. فقط اگر هیچ‌کدام پیدا
نشوند، متن فارسی نادرست نمایش داده می‌شود و یک هشدار در Log بک‌اند ثبت
می‌شود.

## استفاده از فونت یا مسیر دیگر

مقدار `PERSIAN_FONT_PATH` را در `backend/.env` تغییر دهید. برای یک جایگزین
کاملاً متن‌باز (بدون نگرانی لایسنس)، [Vazirmatn](https://github.com/rastikerdar/vazirmatn)
پیشنهاد می‌شود.
